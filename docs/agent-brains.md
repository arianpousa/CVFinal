# Agent brains: models and personalities

Each agent in `.claude/agents/` has a **brain** (the model in its `model:` frontmatter field) and a **personality** (a first name plus traits written into its agent file, under "Name and personality"). Agents sign hand-off log entries as "Name (agent)".

**How models were chosen** (Claude Code subagent `model` field: `opus`, `sonnet`, `haiku`, a full model ID, or `inherit`; see [Claude Code subagents](https://code.claude.com/docs/en/sub-agents)):
- **opus**: hard reasoning. The orchestrator, plus the OpenCV.js and WebAssembly experts, where mistakes are subtle and expensive. (3 agents)
- **sonnet**: strong everyday engineering and design. (6 agents)
- **haiku**: small, well-defined jobs with a checklist and an automated check. (2 agents)
