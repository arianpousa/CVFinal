Library build used

The app self-hosts the official OpenCV.js 4.10.0 build (the file published at docs.opencv.org/4.10.0/opencv.js), taken from the npm package @techstark/opencv-js@4.10.0-release.1, which repackages it with a one-line wrapper fix. It is stored as vendor/opencv-4.10.0.js.
